# OpenCV Camera Image Combiner

A school project that uses OpenCV to capture four images from a webcam and combine them into a single 2×2 image. The application features a user-friendly Tkinter GUI, and the combined image is continuously updated for further image processing and analysis using Beckhoff TwinCAT Vision.
